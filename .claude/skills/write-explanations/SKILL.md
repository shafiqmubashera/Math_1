# Write explanations

- **Hint:** one sentence that points to the first step without giving the answer.
- **Solution:** 2–5 short steps. Show the equation, substitute, and compute. End with the answer in bold.
- **Wrong choices:** one line per wrong option that names the mistake ("This uses n instead of n − 1 in the exponent.").
- Use the course vocabulary: common difference, common ratio, explicit, recursive, f(n), domain, rate of change.
- Math goes in `$…$` (KaTeX).
